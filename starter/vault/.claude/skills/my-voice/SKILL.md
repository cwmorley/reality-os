# Write in the owner's voice

The owner's voice lives in `Voice.md` at the top of this vault. That note is the only source; don't copy its contents here, so there's one version to keep up to date.

1. Read `Voice.md` before drafting.
2. If it still says `Not learned yet`, offer once: "Want me to learn how you write first? It takes about five minutes." If they agree, run the **Learn my voice** prompt in `Prompts.md`. If not, draft plainly and say the draft isn't in their voice yet.
3. Draft in their voice, at the register the recipient calls for. Check it against the **Never share** list in `AGENTS.md`.
4. When they rewrite one of your drafts, offer to add what changed to `Voice.md`. Change it only after they approve the exact wording.
